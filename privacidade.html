Política de Privacidade

Última atualização: 18 de novembro de 2026

Esta política explica como o GTA_Clips Uploader ("o app") usa os dados da conta do Google. O app é uma ferramenta de uso próprio do dono do canal GTA_Clips no YouTube. Ele roda apenas no computador do dono e não é oferecido ao público.

1. Dados que o app acessa

  • Permissão de envio de vídeos ao YouTube (https://www.googleapis.com/auth/youtube.upload), concedida pelo próprio dono do canal na tela oficial de login do Google.
  • O app não lê e-mails, contatos, arquivos do Google Drive, histórico, inscritos, comentários ou qualquer outro dado da conta.

2. Como os dados são usados

  • A permissão é usada apenas para enviar vídeos ao canal do próprio dono, quando ele pede, junto com o título, a descrição e as tags desses vídeos.
  • O app não usa os dados para publicidade, perfil de usuário, venda ou qualquer outra finalidade.

3. Armazenamento

  • O token de acesso do Google fica salvo somente no computador do dono do canal.
  • O app não tem servidores e não envia dados para terceiros. Os dados só vão para o Google/YouTube, no envio dos vídeos.

4. Compartilhamento

Nenhum dado é vendido, alugado ou compartilhado com terceiros.

5. Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. O uso do YouTube segue os Termos de Serviço do YouTube, e o tratamento de dados pelo Google segue a Política de Privacidade do Google.

6. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Como revogar o acesso

O acesso pode ser removido a qualquer momento na página de permissões da Conta do Google. Basta escolher o GTA_Clips Uploader e clicar em "Remover acesso". Também é possível apagar o token salvo no computador.
