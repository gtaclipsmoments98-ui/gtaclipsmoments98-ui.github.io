Política de Privacidade

Última atualização: 18 de novembro de 2026

Esta Política de Privacidade explica como o aplicativo GTA_Clips Uploader ("app") acessa, usa, guarda, compartilha e exclui dados obtidos da Conta do Google de quem o utiliza. O app é mantido pelo responsável pelo canal GTA_Clips no YouTube. Contato: matheusjoseoliveira00@gmail.com.

Resumo: o app pede apenas a permissão de enviar vídeos ao YouTube e a usa só para publicar vídeos no canal de quem fez o login. O app não lê outros dados da conta, não vende dados, não os compartilha com terceiros e não usa servidores próprios: tudo fica no computador de quem usa o app.

1. Quem pode usar o app

O app é uma ferramenta de uso próprio, que roda no computador (Windows) do responsável pelo canal GTA_Clips. Ele não é vendido, não está em lojas de aplicativos e não é oferecido ao público em geral.

2. Dados do Google que o app acessa

Quando o usuário faz o login pela tela oficial do Google, o app solicita um único escopo:

  • https://www.googleapis.com/auth/youtube.upload: permite enviar vídeos para o canal do YouTube do próprio usuário.

Com essa permissão, o Google entrega ao app um token de acesso e um token de atualização, que autorizam os envios. O app não acessa nem solicita:

  • nome, e-mail, foto ou outras informações do perfil da Conta do Google;
  • Gmail, contatos, agenda, Google Drive, Fotos ou outros serviços do Google;
  • vídeos existentes, playlists, comentários, inscritos, estatísticas ou receita do canal.

3. Outros dados que o app trata

Para enviar um vídeo, o app usa o arquivo de vídeo e os textos (título, descrição e tags) que o próprio usuário preparou no computador dele. Esses dados vão apenas para o YouTube, no momento do envio.

4. Como os dados são usados

  • O token é usado somente para enviar ao YouTube os vídeos que o usuário pediu para enviar.
  • Os dados não são usados para publicidade, criação de perfis, treinamento de modelos de inteligência artificial, venda ou qualquer finalidade diferente do envio de vídeos.

5. Armazenamento e segurança

  • Os tokens ficam salvos em um arquivo no computador do próprio usuário, protegido pela conta de usuário do Windows.
  • O app não tem servidores. Nenhum dado da Conta do Google é enviado para o desenvolvedor ou para terceiros.
  • Toda a comunicação com o Google é feita por conexões criptografadas (HTTPS).

6. Compartilhamento

Os dados não são vendidos, alugados nem compartilhados com terceiros. A única transferência é o envio do vídeo, com o título, a descrição e as tags, para o YouTube, a pedido do usuário.

7. Retenção e exclusão

  • Os tokens ficam guardados até o usuário revogar o acesso ou apagar o arquivo de login do app.
  • Para revogar o acesso a qualquer momento, acesse as permissões da Conta do Google, escolha o GTA_Clips Uploader e clique em "Remover acesso". Depois disso, os tokens deixam de funcionar.
  • Os vídeos enviados ficam no canal do YouTube do usuário e podem ser apagados por ele no YouTube Studio.
  • Para pedir ajuda com a exclusão de dados, escreva para matheusjoseoliveira00@gmail.com.

8. Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. Ao usar o app, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

9. Uso limitado (Google API Services User Data Policy)

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

10. Cookies e este site

Este site é apenas informativo. Ele não usa cookies, não tem formulários e não coleta dados de visitantes. A hospedagem é feita pelo GitHub Pages, que pode registrar dados técnicos de acesso conforme a política de privacidade do GitHub.

11. Crianças

O app não é destinado a menores de 13 anos e não coleta intencionalmente dados de crianças.

12. Alterações desta política

Esta política pode ser atualizada. A data da última atualização fica no topo desta página. Se o app passar a usar outras permissões, esta página será atualizada antes disso.
